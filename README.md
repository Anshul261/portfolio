# Anshul Raj Portfolio

A small static portfolio site built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` contains the page content.
- `styles.css` contains the design tokens, layout, responsive styles, and theme.
- `script.js` contains the theme toggle, mobile navigation, section reveal, active nav, and project filters.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
